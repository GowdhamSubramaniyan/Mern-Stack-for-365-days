# Day 63 - JavaScript Data Types

## Learned

### String

- Stores text.
- Written inside quotation marks.

Example:

let name = "Gowdham";

---

### Number

- Stores numeric values.
- No quotation marks.

Example:

let age = 23;

---

### Boolean

- Stores true or false.

Example:

let learningJavaScript = true;

---

### Variables

Used the `let` keyword to store data.

Examples:

let city = "London";

let marks = 95;

let isLoggedIn = false;

## Key Takeaway

JavaScript stores information using different data types. Strings store text, Numbers store numeric values, and Booleans store true/false values. Variables allow us to save these values so we can use them throughout our programs.
