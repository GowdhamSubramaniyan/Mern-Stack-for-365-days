Today I learned about error handling in JavaScript using try and catch.

Error handling allows a program to deal with unexpected problems instead of stopping completely when an error occurs.

The try block contains code that might cause an error:

try {
    // Code that might cause an error
}

If an error happens inside the try block, JavaScript moves to the catch block:

try {
    const data = JSON.parse("hello");
} catch (error) {
    console.log("Something went wrong!");
}

The error variable contains information about what went wrong. I can see the error message using:

console.log(error.message);

The basic flow is:

try
 ↓
Run the code
 ↓
Does it work?
 ↙        ↘
YES       NO
 ↓         ↓
Continue  catch
          ↓
      Handle error

try / catch is useful when working with things that can fail, such as invalid data, JSON parsing, API requests, or unexpected program behaviour.

I also connected today's learning to my previous localStorage project. When loading saved tasks, I use JSON.parse() to convert stored JSON back into a JavaScript array:

function loadTasks() {
    try {
        const savedTasks = localStorage.getItem("tasks");

        if (savedTasks) {
            tasks = JSON.parse(savedTasks);
        }
    } catch (error) {
        console.log("Could not load tasks:", error);
        tasks = [];
    }
}

This means that if the saved data is invalid and JSON.parse() causes an error, the catch block can handle it and reset the tasks instead of allowing the application to fail unexpectedly.

The main takeaway from today is that writing good JavaScript is not only about making code work. It is also about preparing the application for situations where something goes wrong.
