# Day 65 - Operators & Expressions

## Learned

### Arithmetic Operators

- +
- -
- *
- /
- %

### Comparison Operators

- >
- <
- ==
- !=

### Assignment Operator

=

### Expressions

Expressions combine values and operators to produce a result.

Example:

20 + 5

Result:

25

### Event Listener

Used a button click event to execute JavaScript code.

## Key Takeaway

Operators allow JavaScript to perform calculations and comparisons. Expressions combine variables and operators to create values. By using a button with an event listener, JavaScript code can be executed only when the user interacts with the webpage.
