# 1. What are Pre and Post Hooks?

Hooks are functions that execute automatically at specific points during Mongoose operations.

There are two important types:

1. Pre-hooks
2. Post-hooks

## Pre-hook

A pre-hook runs BEFORE an operation.

Example:

```js
projectSchema.pre("save", function () {
  console.log("Project is about to be saved!");
});
```

This function executes before saving a project.

## Post-hook

A post-hook runs AFTER an operation.

Example:

```js
projectSchema.post("save", function (doc) {
  console.log("Project saved:", doc.title);
});
```

This function executes after successfully saving a project.

### Difference between Pre and Post Hooks

| Pre-hook | Post-hook |
|---|---|
| Runs before an operation | Runs after an operation |
| Can modify document data before saving | Can perform actions after saving |
| Example: Format a title | Example: Log successful save |

### Remember

- `pre` = Before.
- `post` = After.

# 2. What are Timestamps?

Timestamps automatically track when a document is created and updated.

Mongoose provides a simple option:

```js
{
  timestamps: true
}
```

When enabled, Mongoose automatically creates two fields.

### createdAt

Stores the date and time when the document was created.

### updatedAt

Stores the date and time when the document was last updated.

### Example

```json
{
  "title": "Learning Tracker",
  "createdAt": "2026-11-16T10:00:00.000Z",
  "updatedAt": "2026-11-16T10:00:00.000Z"
}
```

If we update the project later, `updatedAt` changes automatically.

### Why are Timestamps useful?

- Track when documents were created.
- Track when documents were updated.
- Display recent activity.
- Sort documents by creation date.
- Maintain basic document history.

# 3. What are Virtuals?

Virtuals are calculated properties that are not stored in MongoDB.

They allow us to calculate additional information using existing document fields.

### Example

Imagine a project has this title:

```js
{
  title: "Learning Tracker"
}
```

We want to calculate the title length.

Instead of storing another field, we can create a virtual.

```js
projectSchema.virtual("titleLength").get(function () {
  return this.title ? this.title.length : 0;
});
```

### Accessing the Virtual

```js
const project = await Project.findOne();

console.log(project.titleLength);
```

Expected output:

```text
16
```

The title "Learning Tracker" contains 16 characters.

### Why use Virtuals?

- Calculate additional information.
- Avoid storing unnecessary fields.
- Keep database documents clean.
- Create useful properties from existing data.

# 4. Build – Add Timestamps and Virtuals

Open the existing file:

`models/Project.js`

Make sure your schema options include timestamps and virtuals.

```js
{
  timestamps: true,
  toJSON: { virtuals: true },
  toObject: { virtuals: true }
}
```

Add the following virtual below your schema definition.

```js
projectSchema.virtual("titleLength").get(function () {
  return this.title ? this.title.length : 0;
});
```

This calculates the number of characters in the project title.

# 5. Add a Pre-save Hook

Add this below your schema definition:

```js
projectSchema.pre("save", function () {
  console.log("Saving project:", this.title);
});
```

This executes before saving a project.

It can also be used to modify document data before saving.

---

# 6. Add a Post-save Hook

Add this below the pre-save hook:

```js
projectSchema.post("save", function (doc) {
  console.log("Project saved successfully:", doc.title);
});
```

This executes after successfully saving a project.

### Example Console Output

```text
Saving project: Learning Tracker
Project saved successfully: Learning Tracker
```

Important: Add your hooks before exporting the model.

```js
module.exports = mongoose.model("Project", projectSchema);
```

Also preserve your existing slug generator, author reference and other schema fields.

# 9. Important Things to Remember

| Concept | Purpose |
|---|---|
| Pre-hook | Runs before an operation |
| Post-hook | Runs after an operation |
| Timestamps | Tracks creation and update dates |
| Virtuals | Calculates extra information without storing it |

### Important Notes

1. Pre-hooks execute before the operation.
2. Post-hooks execute after the operation.
3. `timestamps: true` creates `createdAt` and `updatedAt`.
4. Virtuals are not permanently stored in MongoDB.
5. Virtuals can be included in JSON responses.
6. Hooks must be registered before compiling the Mongoose model.
7. Save middleware does not automatically run for `findByIdAndUpdate()`.
