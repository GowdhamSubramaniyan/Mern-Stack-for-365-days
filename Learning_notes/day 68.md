# Day 68 - JavaScript Fundamentals

Today I learned:

- What Booleans are (`true` and `false`)
- How comparison operators work (`>`, `<`, `>=`, `<=`, `===`, `!==`)
- Why `===` is preferred over `==`
- How to use logical operators (`&&`, `||`, `!`)
- How to write simple `if...else` statements
- What arrays are and why they are useful
- How to create arrays and access elements using indexes
- Practiced using `console.log()` to display output

Key takeaway:
Arrays allow me to store multiple related values in a single variable, and comparison operators return Boolean values that can be used to make decisions with `if...else`.
