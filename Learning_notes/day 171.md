## 1. What is Text Search?

Text search allows users to search for words inside text fields in MongoDB documents.

For example, imagine our Projects collection contains:

- Portfolio Website
- Learning Tracker
- Weather Application
- JavaScript Calculator

If a user searches for "JavaScript", MongoDB can find projects containing that word in their indexed text fields.

MongoDB provides the `$text` operator for text searches.

## 2. Understanding Text Indexes

Before using `$text`, we need to create a text index.

A text index tells MongoDB which fields it should search.

Example:

```js
projectSchema.index({
  title: "text",
  description: "text"
});
```

This creates a text index on the title and description fields.

**Important:** MongoDB allows only one text index per collection, but that index can include multiple fields.

## 3. Perform a Text Search

Example:

```js
const projects = await Project.find({
  $text: {
    $search: "JavaScript"
  }
});
```

This searches the indexed text fields for the word "JavaScript".

## 4. Text Search in Your Projects API

Create a search controller:

```js
const searchProjects = async (req, res) => {
  try {
    const { q } = req.query;

    if (!q || !q.trim()) {
      return res.status(400).json({
        message: "Please provide a search term"
      });
    }

    const projects = await Project.find({
      $text: {
        $search: q.trim()
      }
    }).populate("author", "name email");

    res.status(200).json({
      count: projects.length,
      projects
    });

  } catch (error) {
    res.status(500).json({
      message: "Search failed",
      error: error.message
    });
  }
};
```

Add `searchProjects` to your existing controller exports. Do not remove your other controller functions.

### Add the Search Route

In your existing `projectRoutes.js`:

```js
router.get("/search", searchProjects);
```

Make sure this route is placed before any dynamic `/:id` route.

### Test Using Postman

```text
GET http://localhost:5000/api/projects/search?q=JavaScript
```

Expected behaviour:

- Matching projects are returned.
- Missing search term returns status 400.
- No matching projects returns an empty array.

**Note:** MongoDB text search searches indexed words and is not the same as searching for any partial substring.

## 5. What are MongoDB Indexes?

An index helps MongoDB find documents faster.

Imagine you have 100,000 projects.

Without an index, MongoDB may need to examine many documents to find the required project.

With an index, MongoDB can use an organised data structure to locate matching documents more efficiently.

### Simple Example

Imagine a book with 500 pages.

Without an index:
- You read every page to find a topic.

With an index:
- You check the index at the back.
- You jump directly to the relevant page.

MongoDB indexes work in a similar way.

## 6. Create an Index Using Mongoose

Example:

```js
projectSchema.index({ title: 1 });
```

Here:

- `title` is the field being indexed.
- `1` means ascending order.

Descending index:

```js
projectSchema.index({ createdAt: -1 });
```

Here, `-1` means descending order.

## 7. Create Multiple Indexes

You can create indexes for different query patterns.

Example:

```js
projectSchema.index({ title: 1 });

projectSchema.index({ createdAt: -1 });

projectSchema.index({ author: 1 });
```

These indexes can help queries that search or sort using those fields.

**Important:** More indexes are not always better. They use storage and can slow down insert and update operations because indexes also need updating.

## 8. Add Indexes to Your Project Schema

In your existing `Project.js` schema file, add:

```js
projectSchema.index({ title: 1 });

projectSchema.index({ createdAt: -1 });

projectSchema.index({ author: 1 });
```

Keep your existing schema fields, virtuals, middleware, and text index.

Do not create a second text index if you already added one on Day 166.

## 9. Compound Indexes

A compound index contains more than one field.

Example:

```js
projectSchema.index({
  author: 1,
  createdAt: -1
});
```

This can help queries that filter by author and sort by creation date.

Example query:

```js
const projects = await Project.find({
  author: authorId
}).sort({
  createdAt: -1
});
```

The field order in a compound index matters. Design indexes around the queries your application actually runs.

## 10. Check Indexes in MongoDB

You can inspect indexes using MongoDB:

```js
db.projects.getIndexes();
```

This displays the indexes created on the projects collection.

You can also use:

```js
db.projects.getIndexKeys();
```

This displays the indexed fields.
