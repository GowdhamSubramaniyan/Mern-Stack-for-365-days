# 1. setTimeout()

`setTimeout()` tells JavaScript:

> "Wait for some time, then do this ONE time."

Example:

```js
setTimeout(() => {
  console.log("Hello!");
}, 2000);
```

JavaScript does this:

```text
Start
  ↓
Wait 2 seconds
  ↓
Print "Hello!"
  ↓
STOP
```

`setTimeout()` runs the function only once after the specified delay.

### Real-life examples

* Show a message after 3 seconds
* Hide a notification after a few seconds
* Start something after a delay
* Wait before performing an action

### Syntax

```js
setTimeout(function, delay);
```

The delay is measured in milliseconds.

```text
1000 ms = 1 second
2000 ms = 2 seconds
3000 ms = 3 seconds
```

---

# 2. setInterval()

`setInterval()` tells JavaScript:

> "Do this again and again after every X milliseconds."

Example:

```js
setInterval(() => {
  console.log("Hello!");
}, 2000);
```

JavaScript does:

```text
Wait 2 seconds
  ↓
Print Hello
  ↓
Wait 2 seconds
  ↓
Print Hello
  ↓
Wait 2 seconds
  ↓
Print Hello
  ↓
Keep repeating...
```

Unlike `setTimeout()`, `setInterval()` keeps running until we stop it.

### Real-life examples

* Digital clocks
* Countdown timers
* Updating information regularly
* Checking something repeatedly
* Refreshing data

---

# 3. clearInterval()

Because `setInterval()` keeps repeating, we sometimes need to stop it.

First, save the interval inside a variable:

```js
const timer = setInterval(() => {
  console.log("Hello!");
}, 2000);
```

Then stop it:

```js
clearInterval(timer);
```

Think about it like this:

```text
setInterval()   → 🔁 Keep going
clearInterval() → 🛑 STOP
```

---

# 4. setTimeout() vs setInterval()

| Function          | What it does            |
| ----------------- | ----------------------- |
| `setTimeout()`    | Runs once after a delay |
| `setInterval()`   | Runs repeatedly         |
| `clearInterval()` | Stops an interval       |

Easy way to remember:

```text
TIMEOUT = WAIT → DO ONCE

INTERVAL = WAIT → DO → WAIT → DO → REPEAT
```

# 5. What is filter()?

`.filter()` is an array method.

It means:

> "Look through the array and keep only the things that match my rule."

Imagine I have:

```js
const numbers = [1, 2, 3, 4, 5];
```

I only want numbers bigger than 3:

```js
const bigNumbers = numbers.filter(number => number > 3);
```

The result is:

```js
[4, 5]
```

JavaScript checks every number:

```text
1 → bigger than 3? ❌ → remove
2 → bigger than 3? ❌ → remove
3 → bigger than 3? ❌ → remove
4 → bigger than 3? ✅ → keep
5 → bigger than 3? ✅ → keep
```

So `.filter()` is like a security guard.

The guard checks everyone and only lets the people who match the rule through.


JavaScript checks each task:

```text

Go to gym → done? NO → REMOVE ❌

Read a book → done? YES → KEEP ✅
```


# 8. Filtering Active Tasks

Active means the task is NOT finished.

We can use `!`.

`!` means:

> NOT

So:

```js
!task.done
```

means:

> The task is NOT done.

Example:

```js
const activeTasks = tasks.filter(task => !task.done);
```

JavaScript checks:

```text
Learn JavaScript → done? YES → ❌

Build website → done? NO → ✅

Go to gym → done? NO → ✅

Read a book → done? YES → ❌
```

Result:

```text
Build website
Go to gym
```

# 10. Creating One Filter Function

Instead of writing separate code every time, we can create one function:

```js
function getFilteredTasks(filter) {
  if (filter === "all") {
    return tasks;
  }

  if (filter === "active") {
    return tasks.filter(task => !task.done);
  }

  if (filter === "done") {
    return tasks.filter(task => task.done);
  }
}
```

Now we can call:

```js
getFilteredTasks("all");
```

to get all tasks.

```js
getFilteredTasks("active");
```

to get active tasks.

```js
getFilteredTasks("done");
```

to get completed tasks.

# 11. How filter() Works

The basic idea is:

```text
ARRAY
  ↓
filter()
  ↓
Check every item
  ↓
Does it match the rule?
  ↓
YES → Keep it
NO  → Ignore it
  ↓
NEW ARRAY
```

Example:

```js
const activeTasks = tasks.filter(task => !task.done);
```

This means:

> Go through every task and create a new array containing only the tasks that are not done.

---

# 12. Important: filter() Creates a New Array

When we use:

```js
const activeTasks = tasks.filter(task => !task.done);
```

we don't destroy the original `tasks` array.

We create a new array:

```text
tasks
  ↓
[All tasks]

       filter()
          ↓

activeTasks
  ↓
[Only active tasks]
```

The original array is still available.

# 🧠 Cheat Sheet

```js
// Run something ONCE after a delay
setTimeout(() => {
  console.log("Hello");
}, 2000);


// Run something REPEATEDLY
const timer = setInterval(() => {
  console.log("Hello");
}, 2000);


// STOP the interval
clearInterval(timer);


// Get completed tasks
const done = tasks.filter(task => task.done);


// Get active tasks
const active = tasks.filter(task => !task.done);


// Get all tasks
const all = tasks;
```
