## 1. Understand the Application

The Learning Tracker API allows users to manage projects.

Main operations:

- Create a project
- Read all projects
- Read one project
- Update a project
- Delete a project

## 2. Application Architecture

The application follows this structure:

Frontend → Express Routes → Controllers → Services → Repositories → MongoDB

Each layer has a responsibility:

- Routes receive HTTP requests.
- Controllers handle requests and responses.
- Services contain application logic.
- Repositories communicate with the database.
- MongoDB stores application data.

## 3. MongoDB Atlas

MongoDB Atlas provides a cloud-hosted database.

Steps:

1. Create a MongoDB Atlas account.
2. Create a database cluster.
3. Create a database user.
4. Configure network access.
5. Copy the MongoDB connection string.
6. Store the connection string in an environment variable.

Example `.env`:

```env
MONGO_URI=your_mongodb_connection_string
NODE_ENV=production
```

Never upload your real `.env` file to GitHub.

## 4. Prepare Express for Production

Use the hosting provider's assigned port.

```javascript
const PORT = process.env.PORT || 5000;
```

Connect to MongoDB before starting the server.

```javascript
const mongoose = require("mongoose");

const startServer = async () => {
  try {
    await mongoose.connect(process.env.MONGO_URI);

    console.log("MongoDB connected successfully");

    app.listen(PORT, () => {
      console.log(`Server running on port ${PORT}`);
    });
  } catch (error) {
    console.error("Server startup failed:", error.message);
    process.exit(1);
  }
};

startServer();
```

This assumes `app`, `PORT`, and environment variables have already been configured in your existing server file.

## 6. Deploy Backend Using Render

1. Push the project to GitHub.
2. Sign in to Render.
3. Create a new Web Service.
4. Connect your GitHub repository.
5. Select the correct branch.
6. Set the build command to `npm install`.
7. Set the start command to `npm start`.
8. Add `MONGO_URI` in environment variables.
9. Set `NODE_ENV` to `production`.
10. Deploy the service.

Render provides a public URL after successful deployment.

Example:

`https://your-learning-tracker.onrender.com`
