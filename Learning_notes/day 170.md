## 1. What is Pagination?

Pagination means dividing database results into smaller pages instead of returning all records at once.

For example, if we have 100 projects, we can display 10 projects per page.

### Why do we need pagination?

- Improves API performance.
- Reduces the amount of data returned.
- Makes frontend display easier.
- Useful when working with large databases.

## 2. Understanding limit()

`limit()` specifies how many documents MongoDB should return.

```js
const projects = await Project.find().limit(10);
```

This returns up to 10 projects.

## 3. Understanding skip()

`skip()` tells MongoDB how many documents to ignore before returning results.

```js
const projects = await Project.find()
  .skip(10)
  .limit(10);
```

This skips the first 10 projects and returns the next 10.

## 4. Pagination Formula

We use two values:

- page: The page number requested.
- limit: Number of documents per page.

Formula:

```js
const skip = (page - 1) * limit;
```

Example:

| Page | Limit | Skip |
|------|-------|------|
| 1 | 10 | 0 |
| 2 | 10 | 10 |
| 3 | 10 | 20 |
| 4 | 10 | 30 |

## 5. Implement Pagination in Projects API

Example controller:

```js
const getProjects = async (req, res) => {
  try {
    const page = Math.max(1, Number(req.query.page) || 1);
    const limit = Math.min(100, Math.max(1, Number(req.query.limit) || 10));

    const skip = (page - 1) * limit;

    const projects = await Project.find()
      .populate("author", "name email")
      .sort({ createdAt: -1 })
      .skip(skip)
      .limit(limit);

    const totalProjects = await Project.countDocuments();

    res.status(200).json({
      page,
      limit,
      totalProjects,
      totalPages: Math.ceil(totalProjects / limit),
      projects
    });

  } catch (error) {
    res.status(500).json({
      message: "Failed to get projects",
      error: error.message
    });
  }
};
```

### Test in Postman

```text
GET http://localhost:5000/api/projects?page=1&limit=10
```

Second page:

```text
GET http://localhost:5000/api/projects?page=2&limit=10
```

The API returns projects based on the requested page.

## 6. What is a Seed Script?

A seed script automatically inserts sample data into MongoDB.

Imagine creating a new database. It is empty, and you need sample projects to test your application.

Instead of manually creating records using Postman, we can create a seed script.

### Benefits

- Automatically creates sample data.
- Saves development time.
- Makes testing easier.
- Helps populate a new database.

## 7. Create the Seed Folder

Project structure:

```text
learning-tracker/
│
├── models/
│   ├── Author.js
│   └── Project.js
│
├── seed/
│   └── seed.js
│
├── server.js
└── .env
```

## 8. Create seed.js

```js
const mongoose = require("mongoose");
require("dotenv").config();

const Author = require("../models/Author");
const Project = require("../models/Project");

const seedDatabase = async () => {
  try {
    // Connect to MongoDB
    await mongoose.connect(process.env.MONGO_URI);

    console.log("MongoDB connected");

    // Create sample author
    const author = await Author.create({
      name: "John Smith",
      email: "john@example.com"
    });

    // Create sample projects
    await Project.insertMany([
      {
        title: "Portfolio Website",
        description: "A personal portfolio website",
        author: author._id
      },
      {
        title: "Learning Tracker",
        description: "An application to track learning progress",
        author: author._id
      },
      {
        title: "Weather Application",
        description: "A weather application using an API",
        author: author._id
      }
    ]);

    console.log("Sample data inserted successfully");

  } catch (error) {
    console.log("Seeding failed:", error.message);

  } finally {
    await mongoose.disconnect();
    console.log("MongoDB disconnected");
  }
};

seedDatabase();
```

**Note:** This example assumes your Project schema has `title`, `description`, and `author` fields, and your Author schema has `name` and `email`. Add any other required fields from your existing schemas.

## 9. Run the Seed Script

Open your terminal:

```bash
node seed/seed.js
```

Expected output:

```text
MongoDB connected
Sample data inserted successfully
MongoDB disconnected
```

The sample projects and author will now be saved in MongoDB.

**Important:** Running this script multiple times creates duplicate sample records. Use it carefully.
