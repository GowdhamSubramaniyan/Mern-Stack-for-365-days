# 1. What are Virtuals in Mongoose?

Virtuals are properties that are calculated using existing document fields.

They are not stored in MongoDB.

### Example

```js
projectSchema.virtual("titleLength").get(function () {
  return this.title.length;
});
```

If the project title is:

```text
Learning Tracker
```

The virtual returns:

```text
16
```

We can access it using:

```js
const project = await Project.findById(projectId);

console.log(project.titleLength);
```

### Why use Virtuals?

- Calculate additional information.
- Avoid storing unnecessary data.
- Create properties using existing fields.
- Keep database documents clean.

# 2. What are Instance Methods?

Instance methods are custom functions that we attach to a Mongoose schema.

They allow us to perform operations on individual documents.

### Example

```js
projectSchema.methods.getSummary = function () {
  return `${this.title}: ${this.description}`;
};
```

### How to use an Instance Method

```js
const project = await Project.findById(projectId);

console.log(project.getSummary());
```

Example output:

```text
Learning Tracker: My first application
```

### Why use Instance Methods?

- Perform operations on individual documents.
- Reuse document-related logic.
- Keep application code organised.
- Access document properties using `this`.

---

# 3. What is a Pre-save Hook?

A pre-save hook is middleware that executes before a document is saved to MongoDB.

It allows us to perform automatic operations before saving data.

Examples:

- Generate slugs.
- Format data.
- Modify document fields.
- Prepare data before saving.

Today, I implemented a pre-save hook to automatically generate a slug from a project title.

---

# 4. What is a Slug?

A slug is a URL-friendly version of a title.

Example:

**Project title:**

```text
My First JavaScript Project
```

**Generated slug:**

```text
my-first-javascript-project
```

Slugs are commonly used in website URLs.

Example:

```text
website.com/projects/my-first-javascript-project
```

# 5. Build – Automatic Slug Generator

Open the existing file:

`models/Project.js`

The following is an example model using the fields from my existing project application.

```js
const mongoose = require("mongoose");

const projectSchema = new mongoose.Schema(
  {
    title: {
      type: String,
      required: true,
      trim: true
    },

    description: {
      type: String,
      trim: true
    },

    author: {
      type: mongoose.Schema.Types.ObjectId,
      ref: "Author",
      required: true
    },

    // Automatically generated slug
    slug: {
      type: String,
      unique: true,
      lowercase: true,
      trim: true
    }
  },
  {
    timestamps: true,

    toJSON: { virtuals: true },
    toObject: { virtuals: true }
  }
);

// ===================================
// 1. VIRTUAL
// ===================================

projectSchema.virtual("titleLength").get(function () {
  return this.title ? this.title.length : 0;
});

// ===================================
// 2. INSTANCE METHOD
// ===================================

projectSchema.methods.getSummary = function () {
  return `${this.title}: ${this.description || "No description"}`;
};

// ===================================
// 3. PRE-SAVE HOOK
// ===================================

projectSchema.pre("save", function () {
  if (this.isModified("title")) {
    this.slug = this.title
      .toLowerCase()
      .trim()
      .replace(/[^\w\s-]/g, "")
      .replace(/\s+/g, "-")
      .replace(/-+/g, "-");
  }
});

// ===================================
// EXPORT MODEL
// ===================================

module.exports = mongoose.model("Project", projectSchema);
```

**Important:** If my existing Project model contains other fields, I must preserve them instead of replacing the entire schema.

# 6. Understanding the Pre-save Hook

Let's understand the important code:

```js
projectSchema.pre("save", function () {
  if (this.isModified("title")) {
    this.slug = this.title
      .toLowerCase()
      .trim()
      .replace(/[^\w\s-]/g, "")
      .replace(/\s+/g, "-")
      .replace(/-+/g, "-");
  }
});
```

### Explanation

**1. `pre("save")`**

Executes before saving a document.

**2. `this.isModified("title")`**

Checks whether the title has changed.

**3. `toLowerCase()`**

Converts all letters to lowercase.

**4. `trim()`**

Removes unnecessary spaces from the beginning and end.

**5. `replace(/[^\w\s-]/g, "")`**

Removes unwanted special characters.

**6. `replace(/\s+/g, "-")`**

Replaces spaces with hyphens.

**7. `replace(/-+/g, "-")`**

Replaces repeated hyphens with a single hyphen.

# 8. Important Things to Remember

| Concept | Purpose |
|---|---|
| Virtual | Calculates a property without storing it |
| Instance Method | Adds a custom function to a document |
| Pre-save Hook | Executes before saving a document |
| Slug | URL-friendly version of a title |

### Important Notes

1. Virtuals are not stored in MongoDB.
2. Instance methods operate on individual documents.
3. Pre-save hooks run before document saves.
4. `save()` and `create()` trigger pre-save middleware.
5. `findByIdAndUpdate()` does not trigger save middleware.
6. `unique: true` creates a unique index; it is not a normal Mongoose validator.
7. Virtuals can be included in JSON responses using `toJSON: { virtuals: true }`.
