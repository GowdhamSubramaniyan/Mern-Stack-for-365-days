# Day 106 - Fetch API

## Learned

### Fetch API

- `fetch()` is used to request data from a URL.
- It allows JavaScript to communicate with APIs.
- Fetch requests are asynchronous because the response takes time to arrive.

### API

- An API provides data or functionality that another application can request.
- Used a public API to retrieve a post.

### Promises

- `fetch()` returns a Promise.
- `.then()` runs code when the Promise is resolved.
- Used multiple `.then()` calls to process the response.

### JSON

- API data is commonly returned as JSON.
- `response.json()` converts the response into JavaScript data that we can use.

### DOM

- Used `innerHTML` to display API data on the webpage.

## Key Takeaway

Fetch allows a JavaScript application to request data from an API. The application waits for the response, converts the JSON response into usable JavaScript data, and then displays that data on the webpage.
