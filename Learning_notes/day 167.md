# 1. What is Aggregation?

Aggregation is a MongoDB feature that allows us to process, analyse, group and transform documents.

It helps us perform calculations and generate useful information from database records.

### Simple Example

Imagine our Projects collection contains:

| Project | Author |
|---|---|
| Learning Tracker | John |
| Portfolio Website | John |
| Weather App | David |
| Blog Application | John |
| Todo Application | David |

We want to know how many projects each author has created.

Instead of manually counting them using JavaScript, we can use MongoDB aggregation.

### Expected Result

| Author | Total Projects |
|---|---:|
| John | 3 |
| David | 2 |

---

# 2. What is an Aggregation Pipeline?

An aggregation pipeline is a sequence of stages.

Each stage performs a particular operation and passes its results to the next stage.

Example:

```js
const result = await Project.aggregate([
  { $group: { _id: "$author", totalProjects: { $sum: 1 } } }
]);
```

Here:

- `Project.aggregate()` starts the aggregation pipeline.
- `$group` groups documents.
- `$sum` calculates the total number of projects.
- `_id` identifies the grouping field.

# 3. Important Aggregation Operators

## $match

Filters documents based on a condition.

```js
{
  $match: {
    status: "completed"
  }
}
```

Similar to filtering documents using `find()`.

## $group

Groups documents based on a field.

```js
{
  $group: {
    _id: "$author"
  }
}
```

Here, projects are grouped by author.

## $sum

Calculates the sum of values.

```js
{
  $group: {
    _id: "$author",
    totalProjects: { $sum: 1 }
  }
}
```

`$sum: 1` counts each document in the group.

## $sort

Sorts the results.

```js
{
  $sort: {
    totalProjects: -1
  }
}
```

- `1` = Ascending order.
- `-1` = Descending order.

## $project

Selects or renames fields in the output.

```js
{
  $project: {
    title: 1,
    author: 1
  }
}
```

## $lookup

Joins information from another collection.

```js
{
  $lookup: {
    from: "authors",
    localField: "author",
    foreignField: "_id",
    as: "authorDetails"
  }
}
```

This retrieves matching author documents.

## $unwind

Converts an array into separate documents.

```js
{
  $unwind: "$authorDetails"
}
```

# 4. Build – Project Statistics Endpoint

Today I created an aggregation endpoint that calculates how many projects each author has created.

## Step 1: Import the Project Model

Open:

`controllers/projectController.js`

Make sure this import exists:

```js
const Project = require("../models/Project");
```

## Step 2: Create the Aggregation Controller

Add this function to the existing controller file.

```js
const getProjectStatsByAuthor = async (req, res) => {
  try {
    const stats = await Project.aggregate([

      // Stage 1: Group projects by author
      {
        $group: {
          _id: "$author",
          totalProjects: { $sum: 1 }
        }
      },

      // Stage 2: Retrieve author information
      {
        $lookup: {
          from: "authors",
          localField: "_id",
          foreignField: "_id",
          as: "authorDetails"
        }
      },

      // Stage 3: Convert author array into an object
      {
        $unwind: "$authorDetails"
      },

      // Stage 4: Select the required fields
      {
        $project: {
          _id: 0,
          authorName: "$authorDetails.name",
          authorEmail: "$authorDetails.email",
          totalProjects: 1
        }
      },

      // Stage 5: Sort by project count
      {
        $sort: {
          totalProjects: -1
        }
      }

    ]);

    res.status(200).json({
      count: stats.length,
      stats
    });

  } catch (error) {
    res.status(500).json({
      message: "Failed to generate project statistics",
      error: error.message
    });
  }
};
```

Add the function to the existing exports:

```js
module.exports = {
  // Preserve your existing controller functions
  getProjectStatsByAuthor
};
```

If your controller already exports other functions, keep them and add this function to the same object.


# 7. Understand the Aggregation Pipeline

Our pipeline contains five stages.

| Stage | Operator | Purpose |
|---|---|---|
| 1 | `$group` | Groups projects by author |
| 2 | `$lookup` | Retrieves author information |
| 3 | `$unwind` | Converts the author array into an object |
| 4 | `$project` | Selects the required output fields |
| 5 | `$sort` | Sorts authors by project count |

### How the pipeline works

1. MongoDB groups projects belonging to the same author.
2. It counts the projects using `$sum`.
3. It retrieves matching author details using `$lookup`.
4. It processes the author details using `$unwind`.
5. It selects the required fields using `$project`.
6. It sorts the final results using `$sort`.

---

# 8. Important Things to Remember

1. Aggregation processes documents through multiple stages.
2. `aggregate()` executes an aggregation pipeline.
3. `$match` filters documents.
4. `$group` groups documents.
5. `$sum` calculates totals.
6. `$lookup` joins information from another collection.
7. `$unwind` processes array elements.
8. `$project` selects or renames fields.
9. `$sort` sorts the output.
10. Aggregation is useful for reports, statistics and data analysis.

**Important:** This example assumes the Project schema has an `author` ObjectId referencing the Author model and the MongoDB collection is named `authors`.
