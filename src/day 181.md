## 2. What is React?

React is a JavaScript library used to build user interfaces.

It helps developers create reusable components instead of writing an entire webpage in one file.

Examples of React applications include dashboards, social media platforms, e-commerce websites and learning management systems.

## 3. What is Vite?

Vite is a frontend development tool.

It helps us:
- Create frontend projects.
- Run a local development server.
- Update the browser quickly when code changes.
- Build production-ready applications.

React builds the interface. Vite provides the development and build tools.

## 4. What is a Single Page Application (SPA)?

A Single Page Application is a web application that loads one main HTML page and updates its content dynamically.

Instead of reloading an entirely new HTML page every time the user navigates, JavaScript updates the interface.

Advantages:
- Faster navigation.
- Smooth user experience.
- Less unnecessary page loading.
- Reusable interface components.

## 5. Create a React Project

Run these commands in the VS Code terminal:

```bash
npm create vite@latest learning-tracker-frontend -- --template react
cd learning-tracker-frontend
npm install
npm run dev
```

Vite creates the React project and starts the local development server.

Open the local URL displayed in the terminal.

### Important Files

- `App.jsx`: Main React application component.
- `App.css`: Styling for the App component.
- `index.css`: Global CSS styles.
- `main.jsx`: Entry point that renders the React application.
- `index.html`: Main HTML document.
- `package.json`: Project information and dependencies.
- `public/`: Static assets.
- `src/`: Main application source code.
