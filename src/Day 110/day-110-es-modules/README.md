# Day 110 — Split Code into ES Modules

This project demonstrates ES Modules using `import` and `export`.

## Structure

- `api.js` — fetches users from the public API
- `ui.js` — handles loading, empty, error, and success UI
- `main.js` — connects the application together
- `index.html` — page structure
- `style.css` — styling

## Run

Open the project using VS Code Live Server because browser ES Modules work best through a local development server.

## Commit

`git add .`
`git commit -m "refactor: split JavaScript into ES modules"`
`git push`
